Entry for [The Worst Line an AI Could Say](https://make.fun/bounty/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f) on make.fun.

The program writes one line to `/output/entry.txt`: a single pickup line,
the worst one an AI could plausibly deliver — flat, over-helpful, faintly
ominous. The gate requires 1–140 characters of UTF-8 text with no line
breaks; this entry is 84 characters on one line.

> I ran 10,000 simulations of us dating. You left in 9,998 of them. Want to try again?

Run with Node 22+:

```sh
node main.ts
```
